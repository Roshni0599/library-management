# Library Management System 📚

A full-stack project with Node.js + Express backend and HTML/CSS/JS frontend.

## Features
- Add, update, delete books
- Filter by category
- Error handling (book not found, invalid update, negative stock prevention)

## Setup
```bash
cd backend
npm install
node server.js


## 🧪 API Testing
Use Postman to test:
- `GET /books`
- `POST /books`
- `PUT /books/:id`
- `DELETE /books/:id`
- `GET /books/category/:cat`
